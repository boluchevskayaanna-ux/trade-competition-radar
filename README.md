Trade Competition Radar
This is a Python project exploring how countries compete in international trade.
The app allows users to compare suppliers, track changes in market shares, and explore trade trends over time.
It uses trade data from the CEPII BACI database (2017–2024)
Built with Python, Streamlit, Pandas, and Plotly.
Files:
app.py - main Python code for the application
trade.csv - trade data for seven markets from 2017 to 2024
countries.csv and products.csv - country and product names
requirements.txt - libraries needed to run the app
The project is still in development
